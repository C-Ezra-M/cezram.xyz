---
title: Effects of disabling JavaScript
layout: layout.vto
---

**For most purposes, JavaScript support remains optional.** Some features will, however, not work properly with JavaScript disabled.

- **The dark mode switcher**: It is set to dark mode by default. If JavaScript is enabled, your mode selection persists across page visits. If it's disabled, it doesn't.

## How to fix this

- Enable JavaScript support in your browser.
- If you use NoScript (like I do), switch the setting for `neocities.org` to `TRUSTED`.
